# Проверка безопасности (взгляд атакующего)

Проверка: чтение кода доработок и опыты на живой системе. Для каждой находки: что можно было сделать,
как проверено, что исправлено.

## Исправлено

| # | Где | Что можно было сделать | Исправление |
|---|-----|------------------------|-------------|
| 1 | `vpn.py`, `authorize()` | Установка правила polkit и ядер VPN с правами root брала файлы из каталога, который может менять любая программа пользователя, пока открыт запрос пароля. Подмена файла давала правило polkit «разрешить всё» (повышение до root) или ядро с `cap_net_admin`. | Правило передаётся текстом, ядро копируется один раз в каталог root, его SHA-256 сверяется с заранее взятым и ставится только проверенная копия. |
| 2 | `vpn.py`, подписки | Чужой список серверов (подписка) мог содержать собственный JSON: исходящее соединение `direct` (трафик мимо VPN) или плагины Shadowsocks, запускающие другие программы. | Для подписок разрешены только известные протоколы, плагины и «обходные» типы отбрасываются. | 3 | `vpn.py`, `download()` | Любая схема адреса, редиректы https → http и на другие схемы. | Только `http`/`https`, редиректы только на `https` (на `http` лишь если ссылка и была `http`). |
| 4 | Уведомления, тосты, экран блокировки | Текст уведомления `<img src="http://…">` или `![](http://…)`, а также картинка `image-path` с адресом заставляли оболочку открыть сетевое соединение (слежка по IP, запросы на localhost). То же через названия устройств, VPN из подписки, треков. Проверено ловушкой на localhost. | Разрешены только простые теги, остальное показывается как текст; картинки только локальные; ссылки только `http`, `https`, `mailto`. |
| 5 | `dictation` | Распознанная речь печатается в окно с фокусом; посторонний звук мог дать управляющие символы. | Управляющие символы удаляются. |
| 6 | `dictation`, сервер whisper | Сервер работал со всеми правами пользователя. | Запуск с `NoNewPrivileges`, `ProtectSystem=strict`, `ProtectHome=read-only`, `PrivateTmp`, ограничением сетевых семейств (проверено с Vulkan). |

| 8 | Обновления | Обновление ставило «что сейчас на GitHub», а не показанный коммит; подлинность не проверялась. | Ставится ровно показанный коммит (`merge --ff-only`). Если в репозитории есть `allowed_signers`, принимаются только коммиты, подписанные этими ключами (проверено). |
| 9 | Права файлов | История уведомлений и состояния лежали с правами 644 (опасно, если домашняя папка открыта). | `install.sh` ставит 700 на папки и 600 на `notifs.json`. |

## Осталось (решение за вами)

- **Подпись коммитов выключена, пока нет `allowed_signers`.** Включить: настроить подпись коммитов SSH-ключом
  (`git config gpg.format ssh`, `user.signingkey`), положить открытый ключ в файл `allowed_signers`
  в формате `имя ssh-ed25519 AAAA…` и закоммитить. Без этого взлом аккаунта GitHub означает выполнение чужого кода у всех, кто обновляется.
- **Подписки по `http://`** разрешены (так выдают многие панели); атакующий на пути трафика может подменить список серверов.
- Три файла оболочки (`StatusIcons.qml`, `Workspace.qml`, `Panels.qml`) заменены своими версиями, а оригиналы в
  HyperStack обновились. Исправления upstream в этих файлах не доходят, их нужно перенести (предупреждение показывает `install.sh`).

## Проверено и в порядке

Настройки диктовки (строгий белый список значений), запись сочетаний клавиш (проверка клавиш, команды без перевода строки),
создание/переименование файлов на рабочем столе (параметры передаются отдельно, без подстановки в shell), запуск ярлыков
только если файл исполняемый, SHA-256 скачиваемых ядер VPN, права `~/.local/share/hyprstack/vpn` (700/600).
