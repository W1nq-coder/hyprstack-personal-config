# Roadmap

0.1 development: самостоятельное GTK окно, палитра, launcher, dashboard, безопасный пользовательский installer, unit tests, CI и рецепт APK.

Следующий обязательный этап приёмки: доступный GTK display → smoke/визуальная проверка → Alpine aarch64 abuild → реальный Phosh/curtana → исправление найденных проблем → тег v0.1.0. До этого не объявлять MVP готовым.

Затем: событийные D-Bus подписки UPower/NM/BlueZ/MPRIS; пауза обновлений в фоне; VPN список с явным выбором; выбор media player; live dock; UI выбора обоев; экран настроек; Night Light с обнаружением версии/сервиса; измерение энергопотребления.

Оформление Phosh: закрепить версию исходников установленного пакета; минимальный opt-in CSS lockscreen с резервной копией; проверить PIN/звонки/accessibility; только если CSS недостаточно — отдельный версионный plugin/package, без изменения PAM. Blur, overlay/layer-shell и замена home допускаются только после оценки жестов и блокировки.
