# Архитектура

Один Python GTK4 процесс обычного пользователя. `app.py` строит окно 360×800 логических пикселей, адаптивный FlowBox с 1–8 колонками и прокручиваемые страницы. Кнопки/поля имеют минимум 44 px. Физическое разрешение 1080×2400 преобразует compositor; принудительное изменение DPI отсутствует.

`backend.py` запускает штатные CLI с argv без shell, таймаутом 8 секунд, двумя worker threads и защитой от дублирования запросов. D-Bus чтение UPower имеет таймаут 3 секунды. Часы обновляются раз в 30 секунд, системные данные раз в 60 секунд и по кнопке. Нет собственных постоянных демонов. Обновление после пробуждения произойдёт на следующем таймере или вручную. Сигнальные подписки и остановка опроса при скрытии — следующий этап.

Настройки только `~/.config/hyprstack-mobile/settings.json`: light, reduce_motion, favorites (desktop IDs), wallpaper (путь к локальному изображению). Обои показаны отдельным изображением над поиском, не системным wallpaper. Размытие и прозрачность пока отсутствуют. GTK provider не меняет общесистемную тему.

Phosh владеет верхней/нижней панелью, lockscreen, уведомлениями, клавиатурой и edge gestures. Свайп в заголовке переключает страницы. Свайпы с края остаются системными; новый глобальный gesture recognizer не устанавливается. Долгое нажатие на приложение открывает Popover, нажатие снаружи закрывает его. Док обновляется сразу после изменения избранного. Клавиатура для SearchEntry зависит от штатного OSK и требует проверки на Phosh.

Автозапуск — XDG desktop entry, включаемый `--autostart`. Нет нового systemd/OpenRC демона, restart loop или принудительного завершения Phosh. Обычное окно может быть закрыто штатно, Phosh остаётся резервным интерфейсом.
