# Redmi Note 9S / curtana

Цель: Snapdragon 720G, ARM64, 1080×2400, postmarketOS v25.12, pmaports xiaomi-miatoll.
Телефон в данной среде отсутствует. Ни один аппаратный тест не отмечен выполненным.

Перед признанием MVP готовым:

- Проверить GTK окно при масштабе 2/3, портрет/ландшафт, длинных названиях, 44 px hit targets.
- Проверить поиск с экранной клавиатурой, запуск приложений и возвращение в Phosh.
- Проверить edge swipes, долгие нажатия, закрытие Popover снаружи.
- Сравнить UPower с показаниями штатного Phosh, включая первые секунды загрузки.
- Проверить Wi-Fi, Bluetooth, запреты polkit/rfkill, переподключение системных служб.
- Проверить backlight, звук, MPRIS player, настройки VPN без потери сети.
- Проверить блокировку/разблокировку PIN, входящий звонок, уведомления.
- Проверить suspend/resume, работу после нескольких часов, отсутствие зависших subprocess.
- Измерить RSS, idle CPU и расход батареи; целевые бюджеты определить по измерениям.
- Установка, прерывание, откат и повторная установка через SSH на отдельном тестовом пользователе.

Сведения о проблемах зарядки/камеры из upstream device README не являются исправлениями этого проекта. Никакие модули ядра или обходы защиты не устанавливаются.

Responsive: единая политика для 320×640, 360×800, 393×873, 412×915, 540×1200 и 800×360 логических пикселей. Все размеры прошли расчётные unit tests; GUI на них не проверен. На Redmi дополнительно проверить allocation после появления OSK, смену ориентации, Phosh панели, системный шрифт 150/200%, 8+ избранных и дробное масштабирование, если оно доступно. Реальная область меньше физического экрана, делённого на scale.
