# Удаление и восстановление

Это откат пользовательской оболочки, не восстановление прошивки.

1. Откройте терминал Phosh или подключитесь по уже настроенному SSH.
2. Если приложение работает, закройте его. При необходимости найдите PID через `ps`, проверьте командную строку и завершите именно этот PID обычным `kill PID`. Скрипты не убивают посторонние процессы.
3. Выполните из исходников:

```sh
cd Mobile
./scripts/rollback.sh
# uninstall.sh выполняет тот же безопасный откат
```

Если исходники недоступны, используйте установленную копию:

```sh
~/.local/share/hyprstack-mobile/scripts/rollback.sh
```

Журнал создаётся до первой записи. Откат восстанавливает исходные байты и права файлов, удаляет только зарегистрированные файлы, которых раньше не было. Файлы, изменённые пользователем после установки, сначала сохраняются в `~/.local/state/hyprstack-mobile/preserved/`. Настройки и избранное не удаляются. Пустые каталоги и журнал намеренно остаются. Второй откат безопасен.

Если автозапуск мешает войти, временно переименуйте только `~/.config/autostart/io.github.W1nqCoder.HyprstackMobile.desktop` через SSH, затем выполните откат. Он восстановит предыдущую запись, если та существовала до установки. При конфликте сохранённой копии скрипт прекращает работу: сравните обе копии и сохраните нужную вручную.

При потере manifest.json не удаляйте произвольные каталоги рекурсивно: штатный Phosh продолжит работать после отключения указанной записи автозапуска. Сохраните настройки приложения и разберите список файлов установленной версии. Никаких изменений ядра, PAM, modem, загрузчика, boot/cache/userdata или разделов скрипты не делают.
